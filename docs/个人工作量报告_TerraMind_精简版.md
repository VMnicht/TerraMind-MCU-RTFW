## 一、项目概述

mainboard 是一款面向农业场景的智能机器人嵌入式控制平台，从零构建完整固件，实现：

- 差速轮式底盘运动控制（CAN 总线 M3508 电机 ×2）
- 左右双路播撒装置（PWM 舵机翻转 + 编码器电机调速）
- 割草装置（PWM 电调无刷电机）
- 远程指令接收（自定义 UART 通信协议 CmdPort v2.0）
- Xbox 手柄本地操控

### 3.2 软件五层架构

```
┌─────────────────────────────────────────┐
│  App      应用主程序、控制循环、测试框架    │  ← 业务逻辑
├─────────────────────────────────────────┤
│  Device   差速底盘（运动学 + CAN打包）     │  ← 设备抽象
├─────────────────────────────────────────┤
│  Driver   M3508·PWM电机·舵机·电调·手柄·协议│  ← 驱动实现
├─────────────────────────────────────────┤
│  BSP      CAN·编码器·PWM·UART 硬件封装     │  ← 硬件封装
├─────────────────────────────────────────┤
│  HAL      STM32F4xx_HAL + CMSIS          │  ← 厂商库
└─────────────────────────────────────────┘

跨层模块： Algorithm(PID) | OSAL(TaskManager) | Utils(CRC/Vector2D)
```

### 3.3 关键设计要点

**面向对象抽象**
- `SerialDevice` 抽象基类：UART 中断统一分发，新增协议只需继承并重写一个方法
- `ITaskProcessor` 纯虚接口：业务模块与 FreeRTOS 调度解耦，通过 `TaskManager` 声明式注册
- `diff_chassis` 双重构造模式：外部注入（便于测试）或指定 ID 内部创建（便于集成）

**设计模式**
- 策略模式：`ITaskProcessor` 多态注册到不同任务槽
- 模板方法：`SerialDevice` 定义中断接收流程，子类实现协议解析
- RAII：所有驱动对象禁用拷贝，析构自动释放资源

**闭环控制**
- M3508：CAN 总线 PID 电流闭环
- PWM 电机：编码器反馈 + SuperPID 速度闭环（增量式、积分分离、死区、输出限幅）
- 差速底盘：运动学正逆解 + 限幅 + 轮径标定补偿
